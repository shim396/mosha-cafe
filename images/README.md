# 📸 دليل صور موشا — للمصور ولك

حط كل صورة بالمجلد الصحيح **وبنفس الاسم بالضبط**، وراح تظهر بالموقع لحالها.
وإذا صورة بعدها ما وصلت، الموقع يعرض مكانها خلفية بألوان موشا، فالموقع يبين مرتب حتى قبل ما توصل الصور.

| المجلد | اسم الملف | شنو تصوّر | المقاس المقترح |
|---|---|---|---|
| `logo/` | `logo.png` | الشعار بخلفية شفافة أو كريمي | 500×500 مربع |
| `hero/` | `hero.jpg` | لقطة واسعة للمكان أو فنجان بإضاءة دافية (الصورة الرئيسية) | 1920×1080 أفقي |
| `story/` | `story-1.jpg` | الباريستا وهو يحضّر القهوة | 900×1200 عمودي |
| `story/` | `story-2.jpg` | لقطة قريبة (latte art) | 800×800 |
| `story/` | `front.jpg` | واجهة الكافيه من برا مع اللوحة | 1200×900 |
| `menu/` | `mosha.jpg` | مشروب موشا المميز (يطلع بدائرة كبيرة) | 1000×1000 مربع |
| `menu/` | `spanish-latte.jpg` / `tea.jpg` / ... | صور المشروبات (الاسم لازم يطابق `menu-data.js`) | 600×600 مربع |
| `store/` | `beans.jpg` | أكياس محاصيل موشا | 900×900 |
| `store/` | `cups.jpg` | فناجين الورد على الرف | 900×900 |
| `store/` | `winter-pack.jpg` | بكج اللمّة الشتوية | 900×900 |
| `gallery/` | `1.jpg` إلى `9.jpg` | أجواء، زبائن، زوايا، حلويات | عمودية 4:5 (مقاس الموبايل ممتاز) |

## ✅ نصايح للمصور حتى تطلع الصور متناسقة مع الهوية
- إضاءة طبيعية دافية (الصبح أو العصر)، وبدون فلاش.
- خلفيات **كريمي / رخام أبيض / خشب**، وأي لمسة أخضر (نبتة أو ورق) تحلّي الصورة.
- خلي الكوب أو الفنجان وشعار موشا واضح.
- نفس الفلتر لكل الصور: دافي، تباين خفيف، وأخضر هادئ.
- صدّر الصور بصيغة JPG وحجم أقل من 400KB حتى يفتح الموقع بسرعة (تقدر تضغطها مجاناً بموقع squoosh.app).

## 🎬 فيديوهات الواجهة (تتقلّب لحالها)
حطها بمجلد `mosha-cafe/videos/` بهذي الأسماء: `hero-1.mp4` و`hero-2.mp4` و`hero-3.mp4` و`hero-4.mp4`.
- **المدة:** من 6 إلى 15 ثانية لكل فيديو، بدون صوت.
- **الصيغة والمقاس:** MP4 أفقي 1920×1080، ويفضّل حجمه أقل من 5MB.
- **أفكار للتصوير:** صب الحليب ورسم اللاتيه، بخار القهوة، طحن البن، تقديم الحلا، زبائن يضحكون، الواجهة بالليل.
- إذا تريد عدد غير 4 فيديوهات، أو تريد تغيّر مدة كل فيديو، عدّل `HERO_VIDEOS` و`SLIDE_SECONDS` بأول ملف `js/main.js`.
