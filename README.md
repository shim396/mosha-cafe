# موشا كافيه | Mosha Cafe

موقع تعريفي ومنيو إلكتروني تفاعلي لكافيه **موشا (Mosha Cafe)** — سيئون، حضرموت، اليمن.

## المميزات
- **شاشة افتتاحية بخط الشعار المرسوم** مع انتقال انسيابي إلى الواجهة.
- **الوضع النهاري والليلي (`Light / Dark Mode`)** متكامل في الهيدر وقائمة الجوال مع حفظ التفضيل.
- **دعم اللغتين العربية والإنجليزية (`AR ⇄ EN`)** مع عكس الاتجاه (`RTL` / `LTR`) وترجمة كافة الأقسام والمنيو.
- **ناف بار زجاجي شفاف عند التمرير** يتكيّف تلقائياً مع الأقسام الفاتحة والداكنة.
- **منيو تفاعلي بالريال اليمني (`ر.ي` / `YER`)** مقسّم حسب الفئات، مع قسم خاص لتوقيع موشا، ومتجر، ومعرض صور، وخريطة موقع تفاعلية.
